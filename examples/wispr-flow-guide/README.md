# Sample guide: Wispr Flow

This folder contains example screenshots from a paginated brand guide created from Wispr Flow's public website. It demonstrates how the skill's decisions can be presented as a visual, page-by-page guide.

This is an independent demonstration, not an official Wispr Flow brand guide or an endorsement by Wispr. The screenshots show selected pages rather than the complete guide.

## Screenshots

1. `screenshots/01-cover.png` — cover page
2. `screenshots/02-quick-reference.png` — palette and type summary
3. `screenshots/03-foundations.png` — brand foundation and personality
4. `screenshots/04-ai-ready-prompt.png` — copyable AI-ready prompt

The palette, typography, logo, and button examples were identified from the public site; personality, voice, audience, accessibility pairings, and practical logo-spacing recommendations were confirmed or drafted as part of the sample workflow.

Source: [wisprflow.ai](https://wisprflow.ai/)
